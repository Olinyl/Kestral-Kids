# November 9 shared design notes

Keep these owner notes as the reference across role-specific changes. The current pass is the Director preview; items outside it remain follow-up work, not completed features.

- Instructor: a button opens a child; reporting should float, and last-seen time defaults to now with easy adjustment controls.
- Shared account access: Sign in / create account when signed out, Log out when signed in; the signed-out screen lists the preview accounts for switching.
- Account tab: change email and log out. Real account changes wait for the approved backend milestone.
- Patrol: phone-friendly layout; tablet layout should fit one screen where practical.
- Guardian: Alerts replaces Messages.
- Emergency contacts: one complete contact is sufficient; a second is optional. If a second contact is partly entered, complete it or clear it.
- Bib: clarification requested; no new meaning or assignment rule has been invented.
- Navigation: X button for popups. Peer pages already have bottom tabs, so they have no Back button. Nested pages use an arrow beside their title, returning to the parent list. Both X and arrow controls are white with green text and a grey border. (Owner clarification after the Director preview.)
- Text selection should be visible and readable.
- Incidents tab in every role.
- Replace the Interactive demo view selector with a top Change view button in a later shared navigation pass.
- Every role uses a single outer card with the logo/header at the top and fixed bottom navigation. Only the middle content scrolls.
- Separate main sections into cards, following the Director layout.

Director additions: individual parent-alert previews from Children; missing-consent reminders from Overview; scrollable complete overview lists; Guardian-style cards showing program day and group; consistent profile forms; qualifications dropdown; combined child-search dropdown with safe Enter behavior; no child-edit buttons within group lists; top preview notifications.

Auto-assign: default to assigning ungrouped children. Offer a separate preview of rebalancing expected children, preserving checked-in, released and actively missing children, known program days, ability levels, and the six-child instructor limit. Require Apply before any changes.
