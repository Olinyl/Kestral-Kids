# Shared workspace design

This documents the existing visual identity, not a replacement.

- Green ink (#173f39), pale green canvas (#f5f8f7), white work surfaces and restrained green actions.
- System sans-serif as already used in styles.css; ordinary readable headings, 14–16px controls and compact data rows.
- Keep the shared brand header and clearly visible fictional-data banner.
- Use horizontal workspace tabs on desktop and horizontally scrollable navigation on phones.
- Director tasks are an Operate surface: readiness leads, followed by the records requiring action. Counts are factual, derived from the fixture, without decorative charts.
- Tables become labelled stacked rows on narrow screens. Dialogs use native dialog focus trapping, Escape dismissal, explicit Cancel and Save, and visible validation.
- Never use color alone for consent, medical or readiness states.
