# Shared workspace design

This documents the existing visual identity, not a replacement.

- Green ink (#173f39), pale green canvas (#f5f8f7), white work surfaces and restrained green actions.
- System sans-serif as already used in styles.css; ordinary readable headings, 14–16px controls and compact data rows.
- Keep the shared brand header and clearly visible fictional-data banner.
- Keep the brand header and bottom tabs fixed; only the content between them scrolls. Peer tabs have no Back button; popup forms use X, and nested pages use an arrow beside their title.
- Replace the full demo-control bar with a compact account menu. The preview has one fictional profile per role and an Account tab. Real registration and sessions use Piezas after preview approval.
- Text action buttons use 44px minimum targets, 14px/600 text, 8px corners and consistent padding. Single card actions span the available card width; paired card actions split the row equally. Toolbar actions use natural widths; bottom tabs remain equal-width. Green is primary, white/outlined is secondary, red is urgent/destructive. Icon-only close/back/account controls remain 44px targets.
- Director tasks are an Operate surface: readiness leads, followed by the records requiring action. Counts are factual, derived from the fixture, without decorative charts.
- Profile lists, lesson groups, overview entries and summary counts use separate white cards with 12px corners, subtle borders and consistent spacing. Profile facts have visible labels. Use “View details” for opening details; keep specific action labels for alerts, saving and creation. Dialogs use native dialog focus trapping, Escape dismissal, explicit Cancel and Save, and visible validation.
- Never use color alone for consent, medical or readiness states.
- All role cards use the shared lesson details: group name (a stable color based on its name), program day (Saturday amber, Sunday lavender), level and bib (neutral). Show the values without extra Group, Program or Level labels; keep those labels available for screen readers. Keep the Bib label. Missing values say Unassigned, Not assigned or Not recorded. Keep this order, use the same values from the shared child record, and wrap long values. Compact cards use 14px padding and 8–12px spacing; retain 44px action targets and full-width single actions or equal paired actions.

Group colors identify groups; program colors distinguish days. They never encode urgency, ability or readiness. Keep readable names because the palette repeats in very large rosters, and missing or other program days remain neutral.
